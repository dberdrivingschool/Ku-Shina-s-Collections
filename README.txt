KU SHINA'S COLLECTIONS — WEBSITE PACKAGE
==========================================

Open index.html in a browser to preview the website.

Included:
- Responsive white + pink luxury theme
- Uploaded Ku Shina's Collections logo in assets/logo.png
- Multi-section navigation: Home, Shop, About, Gallery, Contact
- Product categories: perfumes, earrings, bracelets, watches, hair clips, head bands, cosmetics, hand bags and belts
- Product filtering
- Click-to-enlarge image viewer
- Download button in the image viewer
- Scroll-reveal animation using IntersectionObserver
- Mobile navigation menu
- Clickable phone numbers using tel: links
- Clickable email using mailto: shinahpure22@gmail.com
- Location link to Google Maps search for Wakiso Town / Matugga Road / Timtom Annex

IMAGE NOTE
----------
The catalog uses representative real-world stock photographs loaded from public image hosts (primarily Unsplash, plus representative hair-accessory images). They are intended as visual placeholders until Ku Shina's actual inventory photographs are supplied. The image sources are listed in image-sources.txt.

INTERNET
--------
Because the product photos and Google Fonts are hosted externally, an internet connection is required for those assets to load. The site itself is plain HTML/CSS/JS and does not require a framework or build step.
